Settings & backup

Keep the dashboard portable. Your records are saved locally, so create backups regularly and keep the HTML file safe.

Job search preferences

Alerts are optional; new discoveries also appear in the job feed.

Open tab + awake device + internet connection are required. Some browsers may throttle background tabs or restrict local-file notifications. Scan frequency is a target, not a guaranteed exact schedule. Scores are approximate; always read the job posting.

Data protection

Browser storage can be erased by clearing website data or changing browsers. Export a JSON backup after application sessions. Import restores your applications, employers, job leads, notes and plan progress.
